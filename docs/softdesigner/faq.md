# ❓ 零基础答疑（FAQ）

> 这里收集的是零基础同学最常卡住的问题，全部用"人话"回答。看不懂一个概念时，先来这里找找；找不到的，带上问题回去看[学习路线](./learning-path)和[预备篇](./prep/p1)——那两条就是为"从零开始"的你准备的。
>
> 原则只有一条：**每个概念先问"它是干什么的"，再问"它叫什么"**。理解用途永远比背定义重要。

---

## Q1：为什么要学二进制？电脑就不能用十个数吗？

**答**：电脑的本质是千千万万个"开关"，而开关只有两种状态：通和断。所以电脑天生只认识两件事——0 和 1。进制只是"数数的规则"：十进制的规则是"满十进一"，二进制的规则是"满二进一"。看几个数就明白了：`0, 1, 10, 11, 100` 用二进制读，就是 `0, 1, 2, 3, 4`。考试不要求你天天做换算，但要求你理解"电脑里的数字、文字、图片，最后都变成了 0 和 1"这件事。换算有固定套路，跟着小例子做两遍就会。

📚 **去哪里学**：[预备篇 P1（二进制与数制）](./prep/p1) → [第一章（数据表示）](./ch01)

## Q2：CPU 到底是什么？

**答**：CPU 是电脑的"总经理"。它自己几乎不存东西，但负责"想"：读一条指令 → 执行它 → 再读下一条，如此反复，一秒几亿次。它由两块核心组成——**运算器**（专门做数学题，像算盘）和**控制器**（指挥运算器干什么，像发号施令的工头）。你不需要背 CPU 内部电路，只需要记住：**CPU 负责执行指令，是电脑的核心**。

📚 **去哪里学**：[预备篇 P2（计算机长什么样）](./prep/p2) → [第一章 1.1（计算机硬件基础）](./ch01)

## Q3：内存和硬盘有什么区别？

**答**：一句话——**内存是桌面，硬盘是抽屉**。正在用的东西摆在桌面上（内存），拿取飞快，但一关机就被清空；长期资料收在抽屉里（硬盘），断电也不丢，但翻找要慢得多。电脑一卡就建议"加内存"，就是因为桌面太小，东西摆不下了。考试爱考两者的对比：谁快、谁贵、断电后谁丢数据——记住这个类比就通了。

📚 **去哪里学**：[预备篇 P2](./prep/p2) → [第一章（存储系统）](./ch01)

## Q4：什么是"复杂度"？O(n)、O(log n) 这些符号是什么意思？

**答**：复杂度是"用数学描述一个问题要花多少功夫"，O 读作"大O"，括号里表示工作量随数据量怎么涨。数据量翻倍时：O(n) 表示工作量也翻倍；O(log n) 几乎没涨（比如查 100 万人只要翻 20 次）；O(n²) 表示工作量涨成 4 倍。考试不考推导，要的是**能比较大小、能判断常见算法属于哪一档**。把它当成一张"难度计价表"，越到后面越有用。

📚 **去哪里学**：[预备篇 P3（数学小工具）](./prep/p3) → [第三章（数据结构）](./ch03)

## Q5：排序为什么重要？

**答**：因为乱的数据没法查。想想查字典：字典按拼音排好了，你翻几下就能找到；如果字是乱排的，只能从第一页看到最后一页。排序就是把数据变得"字典化"，是所有高效查找的前提。它还是"复杂度"最好的练习场——几种经典排序（冒泡、快排、堆排序等）谁快谁慢，是选择题的常客。

📚 **去哪里学**：[第三章（数据结构）](./ch03) → [总结与速查](./summary)

## Q6：什么是数据库？

**答**：数据库就是**用专门软件管理的"超级表格仓库"**。普通 Excel 是给一个人用的小表格，改来改去容易乱、容易冲突；数据库是给很多程序同时用的大仓库，软件自动保证"不乱、不丢、不冲突"。考试考的是表、行、列这些基本概念，和几条标准操作语句（增删改查），**不需要你真去装数据库软件**。先把"表就是一行一行的记录"这个画面装进脑子，后面都好说。

📚 **去哪里学**：[第七章（数据库系统）](./ch07) → [总结与速查](./summary)

## Q7：加密是干什么的？

**答**：加密就是把信息**锁起来再传送**。发信人把"你好"变成一串乱码发出去，只有持对应钥匙（密钥）的人才能打开——偷看的人看到的只是乱码。考试考两种思路的对比：**对称加密**（一把钥匙，锁和开都用它）和**非对称加密**（一把公开的锁 + 一把私有的钥匙）。考得最多的是"谁用哪把钥匙"这类判断，记住这个比喻就能答对大半。

📚 **去哪里学**：[第八章（信息安全知识）](./ch08) → [总结与速查](./summary)

## Q8：为什么有那么多"概念名"要背？

**答**：因为软考考的是"行业通用语言"——这些概念名是计算机行业和同事、和电脑对话时共用的术语。好消息是：**绝大多数概念不用背定义原文，理解"它解决什么问题"就能答题**。所以别逐字背，每遇到一个新概念，问自己一句"它是干什么的？"答不上来，就回对应章节看一眼例子。带着问题学，比从头到尾啃一遍高效得多。

📚 **去哪里学**：先看[学习路线](./learning-path)的章节地图，再按需回到各章。

## Q9：什么是补码，一定要会吗？

**答**：补码是电脑表示"负数"的方法——电脑只有 0 和 1，没有"-"号，所以用一套规则把负数也编成 0/1。**补码是第一章的高频考点，一定要会**，但你不必发明它，只需记住规则：正数的补码就是它本身；负数的补码"取反加一"（先把每一位反过来，再加 1）。找两道例题跟着算三遍，规律就出来了。先看直觉、再学规则，别一上来就啃。

📚 **去哪里学**：[预备篇 P1（先建立直觉）](./prep/p1) → [第一章（数据表示，含例题精讲）](./ch01)

## Q10：完全不会编程，能学软件设计师吗？

**答**：能。上午科目（选择题）考概念和理解，不要求你现场写代码；下午科目虽是写程序题，但考的是**固定套路**（程序填空、改错、画图），更像"英语四六级"式的考试，而不是"编程大赛"。先把[预备篇 P4（编程思维入门）](./prep/p4)看一遍，你会发现"程序就是按步骤做事的说明书"，没什么神秘的。

📚 **去哪里学**：[预备篇 P4（编程思维入门）](./prep/p4) → [第二章（程序设计语言基础）](./ch02)

## Q11：学完一章，怎么知道自己会了？

**答**：三层检验，逐层过关：**① 能说**——合上书，用一句话讲清这章"解决什么问题"；**② 能做**——打开该章的[题库练习](./quiz)，不翻书做对前 5 题；**③ 能教**——给完全不懂的人把某个知识点讲明白。三层都过，这章就真正属于你了。每章的检验点也写在了[学习路线](./learning-path)上。别追求一次记全，章节之间会反复用到前面的内容，第二遍会轻松很多。

📚 **去哪里学**：[学习路线（每章的检验点）](./learning-path) → [题库练习](./quiz)

## Q12：学到一半卡住了，想放弃怎么办？

**答**：先判断卡在哪一层，再对症下药：**概念看不懂** → 回[预备篇](./prep/p1)找对应讲，那里就是专门为你准备的"人话版"；**题目不会做** → 说明概念还没通，先别看答案，回到章节把相关小例子手算一遍；**单纯没动力** → 去[学习路线](./learning-path)看看自己已经走过了哪些关卡，每章的"检验点"就是给你的正反馈。卡住不是退步的信号，是"该复习了"的信号——先退一小步，反而走得更快。

📚 **去哪里学**：[学习路线](./learning-path) → [预备篇 P1](./prep/p1)
