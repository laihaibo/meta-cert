# 预备篇 P5：领域常识（人话版）

> 零基础专栏第 5 讲（预备篇最后一讲）。这一讲把后面章节里最常见的"名词"先用大白话打个招呼：数据库、网络、加密、防火墙、信息安全。
> 目标只有一个：以后见到这些词，脑子里立刻出现一幅画面，而不是一串字母。

## 为什么要先学这个？

第七章（数据库系统）和第八章（信息安全）里，SQL、范式、RSA、防火墙这些词会扑面而来。如果你先有了"数据库 = 大仓库、加密 = 保险箱"这样的直觉，学细节的时候就不会迷路。

这一讲我们只做五件事：

1. 数据库 = 分类整齐的大仓库（Excel 的加强版）
2. 网络 = 寄快递 / 送信
3. 加密 = 保险箱 + 钥匙（对称、非对称、数字签名）
4. 防火墙 = 小区门卫
5. 信息安全 = 家里防盗

学完这一讲，后面两章的名词对你来说都是"老朋友"。

## 概念 1：数据库 = 分类整齐的大仓库（Excel++）

数据库就是"有规矩地存数据的地方"，是 Excel 的加强版。

::: info
**🎯 一句话人话**：数据库 = Excel 加强版：一样是表格，但能存海量数据、能秒查、能多人同时用、还能保证不出错。
:::

::: tip
**💡 类比**：Excel 像你房间里的储物柜，东西随手放；数据库像一个分类整齐的大仓库，每个货架都贴标签、编了号，管理员（数据库系统）一秒就能找到你要的东西。
:::

::: details ✍️ 小例子
**✍️ 小例子**：全校 2000 名学生的成绩单。在 Excel 里找"张三"只能从第一行往下扫，运气不好要翻 2000 行；数据库先把行按学号排好序，再"二分查找"：先看中间那行，判断张三在前半还是后半，每看一次就砍掉一半——最多 log₂2000 ≈ 11 次就能定位到。✓
:::

::: warning
**⚠️ 常见误区**：数据库不是"一张大表"，而是很多张"表"各管一摊（学生表、课程表、成绩表），表之间靠学号之类"对上号"——这就是后面要学的"关系"。
:::

📌 进章学：SQL 查询、范式判别、事务 ACID → [去第七章 数据库系统 ch07](/softdesigner/ch07)。

## 概念 2：网络 = 寄快递 / 送信

网络就是把"数据"当信件寄出去：打包、写地址、一站站送、到了拆开。

::: info
**🎯 一句话人话**：网络 = 把数据装进信封寄走：打包、写地址、一站一站转送、收件人拆开。
:::

::: tip
**💡 类比**：你给朋友寄快递：把东西装进箱子（打包），写上收件地址（IP 地址），快递站（路由器）根据地址一站一站转送，最后送到收件人手里拆箱。
:::

::: details ✍️ 小例子
**✍️ 小例子**：一条 1000 字的微信消息，会被拆成 5 个小包裹（每个 200 字），各自写上相同的收件地址，走不同路线寄出；收件人收到后按序号 1、2、3、4、5 拼回 1000 字。就算第 3 个包裹绕远路晚到了，也能请求补发。✓
:::

::: warning
**⚠️ 常见误区**：数据不是"一根线直达"的——中间要经过很多个"快递站"（路由器）接力；IP 地址是"城市 + 街道"，端口是"房间号"，同一个地址里能区分微信和网页。
:::

📌 进章学：协议分层、TCP 三次握手、IP 地址 → [去第八章 ch08](/softdesigner/ch08)（网络部分）；数据库也要通过网络传输，[第七章 ch07](/softdesigner/ch07) 里会遇到。

## 概念 3：对称加密 = 一把钥匙，锁和开都是它

加密就是"上锁"：不想让别人看的内容，锁起来再送。

::: info
**🎯 一句话人话**：对称加密 = 一把钥匙两用：用它锁上，也用这同一把打开——所以叫"对称"。
:::

::: tip
**💡 类比**：你和朋友共用一个密码锁：你锁上寄出，朋友用同一把钥匙开。前提是双方得提前各有一把一模一样的钥匙。
:::

::: details ✍️ 小例子
**✍️ 小例子**：2 个人互相通信，1 把钥匙就够；3 个人两两通信要 3 把（A-B、A-C、B-C）；4 个人要 6 把。公式：N 个人需要 N×(N-1)÷2 把钥匙。✓
:::

::: warning
**⚠️ 常见误区**：对称加密很快，但有个死结——钥匙本身也得想办法安全地送到对方手里，"送钥匙"的过程又成了新的风险。
:::

📌 进章学：DES / 3DES / AES 的具体算法和密钥长度 → [去第八章 ch08](/softdesigner/ch08)。

## 概念 4：非对称加密 = 锁和钥匙分开

对称加密的钥匙没法安全送，于是换个思路：把锁和钥匙分开。

::: info
**🎯 一句话人话**：非对称加密 = 把"锁"（公钥）到处送人，把"钥匙"（私钥）自己攥着——谁都能锁，只有你能开。
:::

::: tip
**💡 类比**：你在门口挂一把挂锁（公钥），路人把信放进箱子、扣上锁就能寄给你；但开锁的钥匙（私钥）只有你自己拿着。
:::

::: details ✍️ 小例子
**✍️ 小例子**：4 个人通信：每人只保管 1 把私钥，公钥全部公开，总共只有 4 把私钥；对比对称加密要 6 把钥匙，人越多差距越大。✓
:::

::: warning
**⚠️ 常见误区**：公钥是"锁"不是"钥匙"——公钥是给别人"上锁"用的，拿着公钥可开不了锁；能用私钥打开的东西，一定是用对应公钥锁上的。
:::

📌 进章学：RSA、ECC 算法原理、混合加密 → [去第八章 ch08](/softdesigner/ch08)。

## 概念 5：数字签名 = 盖章（防抵赖）

除了"不让人看"，还有两个需求：证明"是我发的"、证明"没被改过"。

::: info
**🎯 一句话人话**：数字签名 = 电子版"盖章"：证明"这东西是我发的、而且没人改过"，赖都赖不掉。
:::

::: tip
**💡 类比**：合同上盖了公章，谁盖的一查便知。数字签名就是用你的私钥"盖章"，别人用你公开的公钥"验章"——私钥只有你有，所以不能抵赖。
:::

::: details ✍️ 小例子
**✍️ 小例子**：你发出"借款 100 元"的盖章内容；收到的人用你公开的公钥验章，确认内容没被偷偷改成"借款 10000 元"、且确实是你发的。✓
:::

::: warning
**⚠️ 常见误区**：签名 ≠ 加密。签名是"盖章证明我发过"，内容可以是公开的；加密是"上锁防偷看"。而且签名用私钥、验证用公钥，方向跟加密正好相反——考试最爱考这个。
:::

📌 进章学：数字签名完整流程 + 数字证书（PKI）→ [去第八章 ch08](/softdesigner/ch08)。

## 概念 6：防火墙 = 小区门卫

网络世界也不是随便进出——门口得有人把守。

::: info
**🎯 一句话人话**：防火墙 = 小区门卫：按名单放行或拦人，进出网络的每一个数据包都要过这一关。
:::

::: tip
**💡 类比**：小区门卫有一张名单：认识的（允许的地址和端口）放行，可疑的（没在名单上的）拦下盘问。防火墙就是网络的"门卫"，按规则检查每个进出的数据包。
:::

::: details ✍️ 小例子
**✍️ 小例子**：规则表从上到下核对：① "快递员" → 放行；② "推销员" → 拦下。一个数据包自称是快递员 → 匹配第 1 条，放行；自称推销员 → 匹配第 2 条，拦下。✓
:::

::: warning
**⚠️ 常见误区**：防火墙不是万能墙——它只管"门口"的进出，拦不住已经混进小区的人（内部攻击），也挡不住规则放行进来的"带病毒快递"（邮件附件）。
:::

📌 进章学：包过滤 / 状态检测 / 代理三类防火墙、IDS 检测方式 → [去第八章 ch08](/softdesigner/ch08)。

## 概念 7：信息安全 = 家里防盗（CIA 三要素）

把上面几件事合起来，信息安全其实就三句话。

::: info
**🎯 一句话人话**：信息安全 = 家里防盗的三件事：不被偷看（保密）、不被改（完整）、随时能用（可用）——考试里叫 CIA 三要素。
:::

::: tip
**💡 类比**：家里防盗：锁好门窗，不让外人看见你的东西（保密）；贵重物品没被调包（完整）；你随时能进门拿东西（可用）。
:::

::: details ✍️ 小例子
**✍️ 小例子**：一封快递信，检查它安不安全就问三件事：① 别人不能拆开看（保密）；② 中途没被偷改内容（完整）；③ 快递一直能正常送达（可用）。✓
:::

::: warning
**⚠️ 常见误区**：安全 ≠ 只有"保密"。信息被改得面目全非而你毫不知情，同样不安全；服务整天瘫痪（不可用）也不算安全——三件事缺一不可。
:::

📌 进章学：CIA 三要素、被动 / 主动攻击、安全法律法规 → [去第八章 ch08](/softdesigner/ch08)。

## 小结与进章学

预备篇收官，五句话总结：

- 数据库 = 分类整齐的大仓库，Excel 的加强版
- 网络 = 寄快递：打包、写地址、一站站送
- 加密 = 保险箱 + 钥匙：对称 = 一把钥匙两用；非对称 = 锁公开、钥匙私有；数字签名 = 盖章防抵赖
- 防火墙 = 小区门卫，管进出、不管内部
- 信息安全 = 家里防盗：不偷看、不改、不瘫痪（CIA）

📌 进章学：SQL 查询、范式判别、事务并发 → [第七章 数据库系统](/softdesigner/ch07)；加密算法细节（DES/AES/RSA）、数字签名流程、防火墙类型 → [第八章 信息安全](/softdesigner/ch08)。
