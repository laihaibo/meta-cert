# 预备篇 P2：计算机长什么样（人话版）

> 零基础专栏第 2 讲。这一讲不需要任何基础，看看你手边的电脑就能看懂。
> 目标只有一个：搞懂"一台电脑里到底有哪些零件，各干各的什么活"。

## 为什么要先学这个？

第一章（计算机系统基础知识）里，CPU 组成、存储层次、总线都是考点。但这些名词的地基是同一件事：**计算机就是"大脑 + 草稿纸 + 文件柜 + 通道"的一台机器**。

这一讲我们只做三件事：

1. 认识计算机的五大部件，各自干什么活
2. 搞懂 CPU、内存、硬盘的"脾气"（谁快谁慢、谁丢谁留）
3. 知道数据在机器里是怎么传来传去的

学完这一讲，第一章的"计算机组成"部分你已经有直觉了。

## 概念 1：计算机有五大部件，各司其职

一台计算机再复杂，拆开看也就五个部分：**运算器**（算数）、**控制器**（指挥）、**存储器**（记东西）、**输入设备**（听你说话）、**输出设备**（回答你）。这五件套就是教科书上说的"冯·诺依曼结构"。

::: info
**🎯 一句话人话**：计算机就五个零件：一个算数的、一个指挥的、一个记东西的、一个听你说话的、一个跟你说话的——没了。
:::

::: tip
**💡 类比**：像一家小饭馆：运算器是掌勺的厨师，控制器是点菜下单的老板，存储器是厨房的架子，输入设备是客人点菜（你的键盘鼠标），输出设备是端出来的菜（你的屏幕）。
:::

::: details ✍️ 小例子
**✍️ 小例子**：你敲键盘打出"好"字：键盘（输入设备）把按键信号送进来 → 控制器（指挥）下令 → 运算器（算数）拼出这个字 → 先放内存（暂存）→ 显示器（输出设备）显示出来。五步，五个部件各干一件事。
:::

::: warning
**⚠️ 常见误区**："存储器"既包括内存也包括硬盘，别把它只当成硬盘；CPU 负责"算和指挥"，**不负责**存东西——存是存储器的事。
:::

## 概念 2：CPU = 大脑，里面住着三兄弟

::: info
**🎯 一句话人话**：CPU 是计算机的大脑，里面主要有三样：运算器负责算数，控制器负责发号施令，寄存器是 CPU 手上攥着的便签纸。
:::

::: tip
**💡 类比**：运算器=计算器；控制器=监工，一直喊"下一步干什么"；寄存器=监工兜里的小便签，记着刚算完还没送走的数。
:::

::: details ✍️ 小例子
**✍️ 小例子**：算 3+5：控制器下令"取 3、取 5、相加"，运算器算出来 8，8 先记在寄存器这张便签上，再送出去。这几步全都发生在 CPU 内部，快得没法察觉。
:::

::: warning
**⚠️ 常见误区**：寄存器**不是内存**——它住在 CPU 里面，数量只有几十个，速度最快、容量最小；考试里"寄存器"和"内存"是两码事。
:::

## 概念 3：内存 = 草稿纸（RAM）

::: info
**🎯 一句话人话**：内存（RAM）是 CPU 的草稿纸：写得快、改得快，但一断电，纸上内容全没了。
:::

::: tip
**💡 类比**：考场打草稿：草稿纸就在手边，随写随改，很方便；但交卷（关机）之后，草稿纸上的字就作废了。
:::

::: details ✍️ 小例子
**✍️ 小例子**：你正在编辑的 Word 文档，内容就躺在内存里；电脑突然断电，没保存的字全丢了——因为草稿纸上的东西还没"抄"进文件柜。
:::

::: warning
**⚠️ 常见误区**：内存越大不代表存得越久，它只是"手边工作台"的大小，关机即清零；常说的 8GB/16GB 内存，说的是草稿纸有多大，不是仓库有多大。
:::

## 概念 4：硬盘 = 文件柜（外存）

::: info
**🎯 一句话人话**：硬盘（外存）是文件柜：读写得慢，但断电不丢，所有文件长期住在这里。
:::

::: tip
**💡 类比**：办公室的文件柜：找文件得起身去翻（慢），但柜子里的东西放一年还在（不丢）。
:::

::: details ✍️ 小例子
**✍️ 小例子**：双击打开一个文档：文件从硬盘（文件柜）被复制到内存（草稿纸），你改完点"保存"，改动又复制回硬盘。所以"没保存就断电"丢的只是草稿纸上的新改动，文件柜里还是旧版本。
:::

::: warning
**⚠️ 常见误区**："保存"是把改动放回**硬盘**，不是内存；删文件进回收站也不算真删——数据还在硬盘上躺着，这正是"数据恢复"软件能找回文件的原因。
:::

## 概念 5：存储层次 = 从手边到仓库（寄存器 → Cache → 内存 → 硬盘）

::: info
**🎯 一句话人话**：从快到慢排：寄存器（便签）→ Cache（办公桌抽屉）→ 内存（书架）→ 硬盘（楼下仓库）。越靠近手边越快、越小、也越贵。
:::

::: tip
**💡 类比**：你写报告：常用词贴在便签（寄存器），常翻的资料放抽屉（Cache），参考书摆书架（内存），一年前的档案搬去仓库（硬盘）。要用什么先从手边找，手边没有才逐级往外取。
:::

::: details ✍️ 小例子
**✍️ 小例子**：读一次内存大约 100 纳秒，读一次硬盘大约 10 毫秒。10 毫秒 = 1000 万纳秒，1000 万 ÷ 100 = 10 万——**内存比硬盘快 10 万倍**。所以"把常用数据放手边"能省下天文数字的时间。✓
:::

::: warning
**⚠️ 常见误区**：Cache 不是内存也不是硬盘，它是 CPU 和内存之间的一层"顺手抽屉"；它的命中率怎么算、映射方式怎么选是考点，这里只记直觉，[进第一章再学](/softdesigner/ch01)。
:::

## 概念 6：总线 = 各部门之间的传话通道

::: info
**🎯 一句话人话**：总线是计算机里传话的通道：数据走"数据总线"，找谁说话看"地址总线"，什么时候说由"控制总线"决定。
:::

::: tip
**💡 类比**：公司里的传话系统：地址总线=信封上的收件人，数据总线=信纸上的内容，控制总线=邮递员喊的"现在送！"。所有部门共用这几条通道，按顺序轮流用。
:::

::: details ✍️ 小例子
**✍️ 小例子**：地址总线有 32 根线，每根线只有 0/1 两种状态 → 2^32 = 4294967296 ≈ 42 亿个"门牌号"（约 4GB）。门牌号就这么多个，多于 4GB 的内存就"叫不到号"——这就是"32 位机器认不出 4GB 以上内存"的原因。
:::

::: warning
**⚠️ 常见误区**：总线不是一根线，是**一组线**（数据/地址/控制三类）；"32 位"有时指 CPU 一次算 32 位，有时指地址总线 32 根，考试里要看上下文。
:::

## 小结与进章学

这一讲的三句话总结：

- 计算机 = 五大部件：运算器、控制器、存储器、输入设备、输出设备，各司其职
- 快慢和保留度是反着来的：寄存器/Cache 快但小，内存快但断电就丢，硬盘慢但永久保存
- 总线是传话通道，地址总线越宽，能"认"到的内存越多

📌 进章学：CPU 性能怎么算（CPI）、Cache 命中率与映射计算、内存地址怎么换算——这些是考点，[去第一章 ch01 学](/softdesigner/ch01)。
