# 预备篇 P1：二进制与数制（人话版）

> 零基础专栏第 1 讲。这一讲不需要任何基础，跟着数数就能看懂。
> 目标只有一个：搞懂"0 和 1 是怎么变成数字的"。

## 为什么要先学这个？

第一章（计算机系统基础知识）里，二进制、补码、浮点数都是考点。但这些名词的地基是同一件事：**计算机只会用 0 和 1 记数**。

这一讲我们只做三件事：

1. 知道二进制是什么、为什么计算机只用 0/1
2. 会数二进制的数
3. 会换算小数字（二进制 ↔ 十进制）

学完这一讲，第一章的"换算"部分你已经有直觉了。

## 概念 1：二进制 = 只有两个数字的数法

我们平时用的是**十进制**：0~9 共十个数字，数到 10 就进位。二进制把十个数字砍到只剩两个：**0 和 1**。

**🎯 一句话人话**：二进制就是只有 0 和 1 两种数字的数法，数到 2 就进一位——世界上根本没有"2"这个数字。

**💡 类比**：十进制像用十根手指头数数，十个数字用完就进位；二进制像开关——只有开和关两种状态，用完了就进位。

**✍️ 小例子**：十进制 1 的后面是 2；二进制 1 的后面直接是 10（它等于十进制的 2）。十进制 9 的后面是 10；二进制 11 的后面是 100（它等于十进制的 4）。

**⚠️ 常见误区**：二进制里的"10"要读作"一零"，**不是**"十"，它的值是 2。

## 概念 2：为什么计算机只用 0 和 1

**🎯 一句话人话**：电路最擅长表达"有电/没电"两种状态，用 0/1 表示既简单又不容易出错。

**💡 类比**：问你"今天来不来"——二选一最好答，绝不会听错；如果非要精确到 10 档亮度，又费劲又容易看错。电路也是这样。

**✍️ 小例子**：一个开关只有"开/关"两种状态 → 对应 1/0。你电脑里有几十亿个这样的小开关（叫晶体管），它们协同工作，演出了电影、微信和游戏。

**⚠️ 常见误区**：0/1 不是"画在纸上的字"，而是电压高低、磁性方向之类的物理状态——但考试里你只管把它们当成 0 和 1 来算就行。

## 概念 3：二进制怎么数数

**🎯 一句话人话**：二进制数数就是 0、1、10、11、100……每两个数就进位，永远不出现"2"。

**💡 类比**：十进制数到 9 就"没数字了"，进位成 10；二进制数到 1 就"没数字了"，1+1 进位成 10。

**✍️ 小例子**：0, 1, 10, 11, 100, 101, 110, 111, 1000 —— 对应十进制 0, 1, 2, 3, 4, 5, 6, 7, 8。✓

**⚠️ 常见误区**：二进制没有数字 2，所以"1 的后面"直接是 10；别以为 10 是十，它是二，11 是三。

## 概念 4：二进制 → 十进制（把它"读"出来）

**🎯 一句话人话**：从右往左，每一位的权重依次是 1、2、4、8、16……（翻倍），把写着 1 的位加起来，就是十进制。

**💡 类比**：像用面额 1 元、2 元、4 元、8 元……的"数字钞票"付款——某一位是 1，说明用上了这张钞票。

**✍️ 小例子**：1011₂ = 8 + 0 + 2 + 1 = 11₁₀。再试一个：11010₂ = 16 + 8 + 0 + 2 + 0 = 26₁₀。✓

**⚠️ 常见误区**：权重从**右**往**左**数，从 1 开始翻倍（1、2、4、8……），最右边一位永远代表 1——所以奇数二进制数最后一位一定是 1，可以当验算口诀。

## 概念 5：十进制 → 二进制（把它"写"回去）

**🎯 一句话人话**：从最大的"数字钞票"开始凑，能减就记 1，减不了记 0，从高位往低位写。

**💡 类比**：还是那套 1、2、4、8、16……的"数字钞票"，从大面额往小面额凑，凑出目标数。

**✍️ 小例子**：13₁₀：13-8=5 → 8 这位记 1；5-4=1 → 4 这位记 1；1-2 不够 → 2 这位记 0；1-1=0 → 1 这位记 1。得到 1101₂。验算：8+4+0+1=13 ✓

**⚠️ 常见误区**：写出来的顺序是"从高到低"（8 那一位在最左边）；1101₂ 和 1011₂ 是两个不同的数（13 vs 11），别写反。

## 概念 6：bit——一个 0/1 到底多大点事

**🎯 一句话人话**：一个 0/1 叫 1 个 bit（比特），几个 bit 连起来就能表示大数字、文字、颜色——bit 越多，能表示的东西越多。

**💡 类比**：一个硬币只能表达"正/反"两件事；两枚硬币能表达 4 种组合；硬币越多，能表达的组合越多。

**✍️ 小例子**：2 个 bit 有 00, 01, 10, 11 共 4 种；3 个 bit 有 000~111 共 8 种；4 个 bit 有 16 种。规律：n 个 bit 能表示 2ⁿ 种。所以 8 个 bit（1 个字节）能表示 256 种。

**⚠️ 常见误区**：别以为"只有 0 和 1"就表示不了大数字——位数够就行：32 个 bit 能表示约 42 亿个不同的值。

## 小结与进章学

这一讲的三句话总结：

- 二进制只有 0 和 1，逢 2 进 1
- 数数就是 0, 1, 10, 11, 100……（对应十进制 0, 1, 2, 3, 4……）
- 换算就靠从右往左 1、2、4、8、16……逐位相加
