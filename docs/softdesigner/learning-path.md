# 🗺️ 零基础学习路线

> **学不动 → 回到预备篇对应讲**，先把地基补上再回来。

这张地图给零基础同学指路：**先花 1 天把预备篇 P1-P5 走一遍**，再按顺序一章一章学；每章学完用「检验点」自测，通过了再进下一章。

## Stage 0 · 预备篇（每讲 30-60 分钟）

| 讲 | 内容 | 预计时长 | 为哪章铺路 |
|----|------|---------|-----------|
| [P1 二进制与数制](/softdesigner/prep/p1.md) | 二进制、十六进制怎么读、怎么算 | 30-60 分钟 | 第一章（计算机系统基础知识） |
| [P2 计算机长什么样](/softdesigner/prep/p2.md) | CPU、内存、硬盘…一台电脑由什么组成 | 30-60 分钟 | 第一章（计算机系统）、第四章（操作系统基础） |
| [P3 数学小工具](/softdesigner/prep/p3.md) | 对数、阶乘、排列组合…够用就好 | 30-60 分钟 | 第三章（数据结构） |
| [P4 编程思维入门](/softdesigner/prep/p4.md) | 变量、循环、条件…用代码的方式想问题 | 30-60 分钟 | 第二章（程序设计语言）、第三章（数据结构）、第六章（面向对象） |
| [P5 领域常识](/softdesigner/prep/p5.md) | 软件是怎么做出来的、信息安全是怎么回事 | 30-60 分钟 | 第五章（软件工程）、第八章（信息安全）、第九章（计算机网络） |
