## 备考建议

1. **重点章节**：第三章（数据结构）、第六章（面向对象）分值最高，务必重点掌握
2. **上午题**：侧重基础知识记忆，注意计算机系统、操作系统、数据结构等概念题
3. **下午题**：侧重案例分析，掌握数据流图（DFD）、数据库设计（ER→关系模式）、UML 建模（类图/序列图）、算法与程序设计（C 语言填空）四类大题套路
4. **时间管理**：上午 75 题 150 分钟，每题约 2 分钟，时间充裕但别在个别难题上恋战
